# 🔍 Проект: Разведка цели и базовый анализ

## 🎯 Цель
Научиться собирать информацию о веб-ресурсе до начала тестирования.

## 🛠️ Инструменты
- nmap (сканирование портов, версии сервисов)
- whois / nslookup (информация о домене)
- BuiltWith (определение технологий)
- Браузер + DevTools (анализ трафика)

## 📋 Что сделано
1. Сканирование портов: `nmap -sV scanme.nmap.org`
2. Whois-запрос: определение провайдера и страны
3. Анализ технологий: веб-сервер, язык, CMS
4. Проверка robots.txt на наличие скрытых путей
5. Фиксация результатов в отчёте

## 📊 Результат
- Найдено открытых портов: 3 (22/ssh, 80/http, 9929/nping-echo)
- Веб-сервер: Apache 2.4.7
- Файл robots.txt: отсутствует
- Риски: устаревшая версия Apache (требует проверки на CVE)
