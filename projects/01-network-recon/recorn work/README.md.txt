# 🔍 Проект 1: Сетевая разведка и анализ поверхности атаки

## 🎯 Цель задачи
Провести пассивную и активную разведку учебной цели (`scanme.nmap.org`) для выявления открытых портов, запущенных сервисов и их версий. Оценить потенциальные векторы атаки.

## 🛠️ Использованные инструменты
- **Nmap** (сканер портов и сервисов)
- **Командная строка Windows/Linux**

## 📋 Ход работы

### 1. Сканирование портов и версий
Была выполнена команда:
`nmap -sV -oN proof_nmap.txt scanme.nmap.org`

**Результаты сканирования (из proof_nmap.txt):**
- **Порт 22 (TCP):** OpenSSH (версия зависит от вывода)
- **Порт 80 (TCP):** Apache httpd (версия зависит от вывода)
- **Порт 9929 (TCP):** Nping echo

### 2. Анализ полученных данных
- Сервер отвечает на ICMP-запросы (Host is up).
- Веб-сервер Apache работает на стандартном порту 80.
- Обнаружен нестандартный порт 9929 (служебный порт утилиты nping).

## 🚨 Оценка рисков и выводы
1. **Устаревшее ПО:** Если версии OpenSSH или Apache не обновлены, они могут содержать известные уязвимости (CVE). Требуется проверка по базам NVD.
2. **Нестандартные порты:** Открытый порт 9929 может указывать на наличие отладочных или служебных инструментов, которые часто забывают защитить.

## 📎 Приложения
- `proof_nmap.txt` — оригинальный вывод сканера Nmap (сырые данные).
