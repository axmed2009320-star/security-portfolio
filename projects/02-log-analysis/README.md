# 📊 Проект 2: Анализ логов на аномалии

## 🎯 Цель задачи
Разработать инструмент для автоматического поиска признаков атак (SQLi, XSS, сканирование) в логах веб-сервера.

## 🛠️ Использованные инструменты
- **Python 3** (скрипт анализа)
- **Тестовые логи** (симуляция реальных атак)

## 📋 Что делает скрипт
1. Читает файл логов (`access.log`)
2. Ищет паттерны SQL Injection: кавычки `'`, ключевые слова `OR`, `UNION`
3. Ищет паттерны XSS: теги `<script>`, обработчики `onerror`
4. Анализирует частоту запросов по IP для выявления сканирования
5. Выводит статистику и список подозрительных IP
